Put NASA Giovanni CSV files here, named  <variable>__<place>.csv  (two underscores).

  sst__florida_keys.csv     MODIS Aqua sea surface temperature, box -81.8, 24.4, -80.3, 25.3
  sst__miami.csv            same variable, box -80.2, 25.4, -79.9, 26.0
  no2__miami.csv            OMI tropospheric NO2 (OMNO2d), box -80.5, 25.5, -80.1, 26.4
  no2__tampa.csv            box -82.8, 27.7, -82.2, 28.2
  no2__orlando.csv          box -81.7, 28.3, -81.1, 28.8
  no2__jacksonville.csv     box -82.0, 30.1, -81.4, 30.6

Giovanni: plot type "Time Series, Area-Averaged", monthly data, longest dates, download CSV.
Boxes are west, south, east, north. Units are converted automatically (Kelvin to C, NO2 divided by 1e15).
Any other file named <variable>__<place>.csv (for example temperature__miami.csv) replaces the NASA POWER data for that place.
